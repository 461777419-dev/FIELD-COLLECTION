# 图集 × 画板预览（2026-11-06）

预览入口：http://127.0.0.1:4177/ 。本次不打包桌面安装程序。

## 本次功能

- 外层工具栏增加“一键去色 / 恢复色彩”：选中时作用于选区，否则作用于整张画板；锁定元素跳过。使用画板撤销恢复，图库原图不改；保存文件和 PNG 合成包含去色属性。
- 去掉右下装饰与缩略导航。设置中说明偏好自动保存、画板内容需手动保存，AI 沿用左上共用设置。
- 每个画板以唯一编号绑定一个图库文件夹及磁盘目录，同名不会误合并。画板或图库中新建、改名，在进入画板、窗口聚焦或“同步素材”时同步。
- 图集与画板的图片、视频素材自动双向同步，已移除“同步素材”按钮。编辑后短暂防抖同步，图库变化约 2.5 秒内读取；错误会提示并自动重试，也有失败时的重试入口。首次网格排列并适应视图，后续新增放在原内容右侧。
- 自动同步时，画板导入的图片、视频注册到图库；已有图库素材保留原记录。在对应目录生成 `.画板.json` 和必要的共享文件入口。
- 删除画板不删除图库文件夹及原素材；删除图库文件夹时归档关联画板，原素材按原图库逻辑移回根目录。未保存的编辑发现关联目录已删除时先写恢复备份。

## 数据与恢复

默认数据位于本项目 `data/`，如设置 REFERENCE_BOARD_DATA_DIR 则以其值为准。

- 首次关联前备份：`backup-before-board-links/`。
- 当前工程：`board/document.json`；上次保存：`board/document.previous.json`。
- 删除归档和编辑恢复副本：`board/archive/`。暂未提供归档恢复按钮，请保留此目录，恢复时需将其中的 board 内容重新导入工程。
- 原图：`media/`；画板媒体入口：`board/media/`。

共享素材使用同盘硬链接，多个文件名共用一份文件数据。不要用外部软件直接覆盖编辑这些共享文件：修改内容会影响同一原图的所有入口。若要独立编辑，请先复制到图库外另存。本地文件系统需支持硬链接，不支持时保存会报错，不会悄悄复制多份。

本次不监控资源管理器中直接新增、删除或改名；请在软件内整理。素材新增、删除自动同步；手动保存用于保留画板完整编辑历史及相机状态。任一侧删除素材都会从全部关联画板移除并放入图集回收站，共用素材先提示影响范围。回收站恢复会还原原有卡片位置，画板撤销自己发起的删除也能恢复素材。彻底删除沿用图库的不可恢复确认。

```powershell

```
